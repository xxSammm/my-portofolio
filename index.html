Tentang Saya

Saya merupakan lulusan SMK Citra Negara Depok dari jurusan Pengembangan Perangkat Lunak dan Gim (PPLG), sehingga saya memiliki dasar dalam pengembangan aplikasi dan website. Saya juga memiliki pengalaman sebagai IT Support, yang membantu saya memahami troubleshooting perangkat keras maupun perangkat lunak serta memberikan dukungan teknis kepada pengguna.

Saya memiliki keahlian di bidang UI/UX Design, Frontend Development, dan Branding. Saat ini saya berbasis di Depok, Jawa Barat, Indonesia.

Melalui portofolio ini, saya ingin menampilkan berbagai project, keterampilan, dan pengalaman yang telah saya kerjakan sekaligus mendokumentasikan perkembangan saya dalam mempelajari teknologi.
